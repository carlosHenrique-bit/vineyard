# Vineyard

O **Vineyard** é um projeto de e-commerce de canecas personalizadas, desenvolvido com o objetivo de criar uma aplicação Full Stack.

A proposta é construir uma loja virtual com catálogo de produtos, carrinho de compras e integração entre Front-end, Back-end e banco de dados.

##Tecnologias

Atualmente: HTML5 e CSS3.

Planejadas: JavaScript, Node.js e banco de dados.

##Status

**Em desenvolvimento.**

A página inicial já possui uma estrutura visual, enquanto a página de produtos e outras funcionalidades ainda estão sendo desenvolvidas.
